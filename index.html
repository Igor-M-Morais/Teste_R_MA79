Sistema de Cadastro de Motores em Python

Documentação técnica do algoritmo monolítico desenvolvido para gestão e teste de especificações de motores elétricos.

Contexto do Desenvolvimento

Jaraguá do Sul - SC

Este projeto foi desenvolvido durante as atividades práticas de programação no CentroWEG, a unidade do SENAI localizada dentro do parque fabril da WEG em Jaraguá do Sul, Santa Catarina.

O objetivo do exercício foi construir uma aplicação monolítica em arquivo único (cadastro_motores.py) capaz de simular um sistema CRUD (Create, Read, Update, Delete) em memória RAM, utilizando apenas estruturas nativas do Python sem dependência de bancos de dados externos.

Como o Código Funciona

O programa é estruturado em três pilares principais dentro do mesmo arquivo:

1. Armazenamento em Memória

Utiliza uma lista global (motores = []) funcionando como um array dinâmico. Cada motor é representado por um dicionário contendo chaves como id, modelo, fabricante, potencia_cv, tensao_v e rpm.

2. Modularização por Funções

Cada operação do sistema é isolada em uma função específica: cadastrar_motor(), listar_motores(), buscar_motor(), atualizar_motor() e excluir_motor(), facilitando a manutenção e leitura.

3. Validação e Loop Principal

Blocos try/except impedem que entradas inválidas (como texto no lugar de RPM ou potência) quebrem a execução. A função menu() mantém o sistema ativo em loop while True até o usuário encerrar.

Mapeamento das Funções

Função Operação CRUD Responsabilidade no Sistema
cadastrar_motor() Create Coleta dados via terminal, valida tipos numéricos e adiciona novo dicionário à lista com ID autoincremental.
listar_motores() Read Percorre o array motores e exibe todos os equipamentos cadastrados formatados no console.
buscar_motor() Read (Filtro) Filtra registros por ID exato ou correspondência parcial (case-insensitive) no modelo ou fabricante.
atualizar_motor() Update Localiza o motor pelo ID e permite alterar campos específicos mantendo os valores atuais caso fiquem em branco.
excluir_motor() Delete Identifica o índice do registro na lista e o remove da memória utilizando o método .pop().

Estrutura de Dados Utilizada

Exemplo de como os motores são estruturados na memória antes da interação do usuário:
